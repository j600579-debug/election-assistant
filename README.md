# Smart Election Assistant

This project helps users understand the election process.

## Features
- Voting steps explanation
- Required documents
- Timeline information
- Simple chat-based interaction

## How it works
User types a question and the assistant gives answers based on keywords.

## Technologies used
- HTML
- CSS
- JavaScript
